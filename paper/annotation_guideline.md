Annotation guideline (pilot: meter, rhyme, metaphor, affect)

Units: annotate at couplet level (two lines = couplet). Each line has misra1 and misra2.

Meter (Arud): label with meter class (e.g., 'Ramz-e-Kamil', use numeric code). For pilot, use coarse classes: bahar-ramz/short, bahar-ramz/long, unknown.

Mark syllable pattern if possible as H/L/... where H=heavy, L=light.

Rhyme/qaafiya/radif:

Mark radif (fixed refrain) if present — the exact string that repeats verbatim across couplet line ends.

Mark qaafiya — the rhyming unit immediately before radif (if radif exists) or final rhyme unit.

Metaphor: binary metaphor: yes/no. If yes, tag domain from list: [wine, night, rose, separation, divine, beloved, journey, sleep, intoxication].

Dead/stock phrase annotated as metaphor_dead if it's highly conventionalized (e.g., 'gul' for beloved used as stock).

Affect: choose one label per couplet: longing, ecstasy, resignation, irony, devotion, anger.
